# R Data Analysis — Iris Dataset

This repository contains an R data analysis project based on the built-in `iris` dataset.

## Tasks

The project includes:

### 1. Data Preparation

* Rename columns using `snake_case`
* Convert `species` to a factor
* Calculate `sepal_ratio` and `petal_area`
* Sort observations by `sepal_ratio`
* Add an observation identifier

### 2. Descriptive Statistics

* Calculate mean, standard deviation, minimum, and maximum for each species
* Count observations by species

### 3. Data Reshaping

* Convert data from wide to long format
* Calculate mean values for each measurement and species
* Convert the result back to wide format

### 4. Filtering and Comparison

* Filter observations according to specified conditions
* Find the observation with the maximum sepal length for each species
* Compare sepal length with the mean for the corresponding species

## Technologies

* R
* tidyverse
* dplyr
* tidyr

## Dataset

The project uses the built-in `iris` dataset containing 150 observations of three iris species: Setosa, Versicolor, and Virginica.
